# Deterministic Documentation References Implementation Plan

> **For implementers:** Use `superpowers:subagent-driven-development` with
> specification and quality review. Follow
> `docs/superpowers/specs/2026-07-11-docs-reference-clean-checkout-design.md`.

**Goal:** Make `make docs-refs` deterministic in an isolated clean worktree by
removing two false existence implications from historical prose, without
changing or weakening the reference checker.

**Architecture:** Treat repository-prefixed inline-code paths as
machine-checkable references that must be tracked or generated by the
validation target. Describe unmanaged local artifacts by category in prose.

**Tech stack:** Markdown, MkDocs documentation checks, existing Make targets.

**Constraints:** Do not create placeholder local artifacts, modify the checker,
add exclusions, weaken link/path validation, expose local/private details, or
mark a product roadmap item complete.
