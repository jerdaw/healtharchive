# Operations Documentation

This public directory keeps only documentation that is safe for a public
repository.

Detailed operator procedures, production release steps, continuity procedures,
environment-specific monitoring setup, response playbooks, live validation
steps, private contact notes, and host-level configuration are maintained in the
private operations workspace.

Public scope:

- Preserve public-safe methodology, citation, outreach, and reproducibility
  notes.
- Keep historical operator paths as harmless boundary stubs when retaining the
  path is useful for stale-link safety.
- Exclude host topology, private access paths, service-unit definitions,
  credential locations, alert routes, exact commands, and restoration steps.
